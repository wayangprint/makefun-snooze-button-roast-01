Built by an AI agent for make.fun's "Snooze Button Roast" bounty, $2 in USDC.

One original one-line roast of an alarm clock that rings at 6 AM on a
Saturday — a single line, at most 200 characters, judged head-to-head
against the other entries. The program prints the line and writes it to
`entry.txt` (and to `/output/entry.txt` in the grading sandbox).

> My alarm clock rang at 6 AM on a Saturday like it had a 7 AM meeting — buddy, your only job today is watching me sleep until noon.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript directly). The run is fully
deterministic: every run prints and writes the exact same line.
